# phpz 文档建设计划

## 目标与约定

- Zig 版本统一为 `0.17.0`。

- 使用 [Zine](https://github.com/kristoff-it/zine) 构建文档站点，直接编写原生 `.smd` 文件。
- 首版编写简体中文文档，同时预留同名的英文空文件。
- 按 `zh-CN/` 和 `en-US/` 分目录，文件不使用 `_CN` 等语言后缀。
- 使用 Zine 原生多语言配置，默认 `en-US`；英文完成简介及 4 个入门页面，其他空文件由 Zine 跳过。
- 站点地址为 `https://happystraw.github.io/phpz/`，默认英文入口；中文位于 `/phpz/zh-CN/`，通过原生翻译关联切换当前章节。
- 参考 [ext-php-rs 文档目录](https://ext-php.rs/toc.html) 的“入门 → 参考指南 → 进阶主题”结构，根据 phpz 的实际接口调整。
- 文档内容以当前源码和可运行示例为依据，现有 README 作为资料来源，涉及接口行为时重新核对源码。

## 目录组织

```text
docs/
├── PLAN.md
├── README.md                  # 文档预览、构建和维护说明
├── zine.ziggy
├── layouts/
│   ├── templates/base.shtml
│   └── doc.shtml
├── i18n/                      # en-US.ziggy、zh-CN.ziggy 界面翻译
├── assets/
│   └── phpz/style.css
└── content/
    ├── zh-CN/
    │   ├── index.smd
    │   ├── getting-started/
    │   ├── reference/
    │   └── advanced/
    └── en-US/                    # 与中文保持相同相对路径，首版完成简介与入门，其余为空
        ├── index.smd
        ├── getting-started/
        ├── reference/
        └── advanced/
```

- 页面文件使用小写英文名称，多个单词以连字符连接。
- 首页及包含实质内容的章节概览使用 `index.smd`，不创建仅列子链接的目录页。
- 中英文页面保持相同相对路径；有正文的对应页面设置相同的 `.translation_key`，使用 Zine 原生翻译关联，空文件不添加元数据。
- 中文页面包含有效的 Ziggy frontmatter；未完成页面标记为草稿，正式导航只链接已发布页面。
- 英文完成简介、环境安装、Hello World、工作原理及开发工具，其余 35 个预留文件保持为空；翻译时补齐正文、frontmatter 和导航。

## 相对 ext-php-rs 的调整

| ext-php-rs 主题 | phpz 的组织方式 |
| --- | --- |
| `cargo php` | 骨架生成、Zig 构建、Stub 生成和 PHPT 测试 |
| Macros | PHP Stub、`phpz.module`、`phpz.function`、`phpz.Class` 和 `Ctx` |
| Rust 类型与转换 trait | PHP / Zig 类型对应、Zval 操作和所有权规则 |
| Zval Ownership | 基础所有权章节，并在涉及引用计数的示例中说明责任 |
| Bailout Guard | phpz 的 bailout 边界、资源清理与相关接口 |
| Advanced Topics | 按 phpz 实际能力增加对象 GC、对象处理器、运算符及平台集成 |

Async、Embedded PHP、Custom SAPI、Worker Mode 等主题，待项目具有对应能力和可验证示例后再纳入。迁移指南在出现具体的接口迁移需求时添加。

## 站点实现

- 固定 Zine 版本，使用与该版本匹配的配置和模板语法。
- 文档独立构建，在 `docs/README.md` 记录预览与静态生成命令。
- 顶部提供项目名称、文档入口和 GitHub 链接。
- 左侧提供章节导航和当前页标记。
- 正文支持标题、代码块、表格及提示内容，保证手机端可阅读。
- 使用原生 locales 和 i18n 提供英文、简体中文入口与界面翻译。
- 布局参考 VitePress，强调色使用 Zig 官网黄色 `#f7a41d`，支持手动亮暗切换并保存偏好，首次访问遵循系统主题；不添加搜索。
- 构建产物和缓存加入 `.gitignore`。
- 通过 `zig build docs` 生成 API，再用 Zine 原生资源参数安装到 `/phpz/api/`；站点直接使用 Zine 构建和预览。
- 配置已知 GitHub Pages 地址及 `/phpz/` 子路径；当前完成本地站点，部署另行安排。

## 编写规范

- 文档示例工程统一使用 `my_php_extension` 作为扩展名，生成命令、文件名、INI 前缀及加载路径保持一致。

- 使用简体中文解释，保留 API、类型和命令的原始名称。
- 常规章节按“用途 → 最小示例 → 行为说明 → 注意事项”组织，按内容需要精简。
- 示例优先复用 `examples/skeleton` 和 `examples/my_php_extension` 中的现有用法。
- 明确区分 Stub 声明、编译期绑定和运行期注册。
- 涉及 Zval、字符串、数组、对象和资源时，说明借用、复制、所有权转移及释放责任。
- 涉及错误、异常和 bailout 时，说明控制流与清理行为。
- 涉及 PHP 版本、NTS/ZTS 和平台差异时，标明适用范围。
- 底层接口章节链接到相关源码，避免正文变成全部 API 的机械罗列。
